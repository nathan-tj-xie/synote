# PROTOTYPE：手动 git 面板 UI（#11）

一次性原型，用来对比 git 面板的三种结构，选定后丢弃。所有 git 动作都是内存里的桩，不碰真实仓库。

```bash
pnpm install && pnpm dev
```

- `?variant=A|B|C`（或底部黄条的 ← → / 键盘方向键）切换变体：
  - **A 侧栏 · 暂存区**：VSCode 式活动栏 + 侧栏，真暂存区（stage/unstage），历史在侧栏底部折叠。
  - **B 状态栏 + 审阅页 · 勾选提交**：平时只占状态栏；点"N 处更改"进全窗口审阅页（左勾选列表、右 diff），历史是同页的一个标签。
  - **C 右侧时间线**：右侧抽屉按"远端待拉取 → 未提交 → 未推送 → 历史"排成时间线，push/pull 挂在对应节点上，默认提交全部、可排除。
- 黄条下拉框切换 git 场景：正常、干净、合并中、push 被拒（非快进）、无凭据、缺提交身份、没有 git。
- "状态"按钮显示完整的内存状态。
- 快捷键标签（⌘⇧G 等）只是示意，没有接线。
